## Gidel 사 FPGA 기반 머신비전 솔루션 — VCANUS가 한국에서 공급합니다

**Gidel** (이스라엘)은 30년 이상 FPGA 기반 머신비전 분야에 집중해 온 글로벌 전문 기업으로, **PCIe 프레임 그래버**, **FPGA + NVIDIA Jetson 통합 엣지 컴퓨터**, **카메라 시뮬레이터**, **이미징 IP 코어 라이브러리**까지 비전 파이프라인 전 영역을 아우르는 제품군을 제공합니다.

**VCANUS는 Gidel의 한국 공식 총판**으로서, 산업비전 · UAV · 방산 · 의료 · 스포츠 AR · ATE 등 국내 다양한 분야의 고객사를 대상으로 제품 공급, 기술 지원, 커스텀 통합 서비스를 제공합니다.

**Gidel 제품군의 특징**

- **FPGA 기반 결정론적 처리** — 하드웨어 수준 실시간 성능, OS 지터 없음, Zero Frame Loss
- **다중 카메라 인터페이스** — GigE Vision · CoaXPress-12 · Camera Link 단일 플랫폼 지원
- **실시간 FPGA 압축** — JPEG · Lossless · Quality+ · HDR IP 코어
- **다중 카메라 동기화 (InfiniVision)** — 100대 이상 카메라 나노초 수준 동기화
- **AI 엣지 컴퓨팅 통합** — FPGA + NVIDIA Jetson 결합 엣지 컴퓨터
- **개발 도구 & 커스터마이징** — ProcVision Suite · GIL · CamSim · SkyBoost SDK

## Imaging Library — GIL & 개발 도구

**Gidel 하드웨어에 특화된 통합 개발 도구 생태계.** 검증된 IP 코어 재사용으로 신뢰성을 확보하고, 비 FPGA 전문가도 커스텀 비전 알고리즘을 개발할 수 있습니다.

**GIL (Gidel Imaging Library)**
- 30년 FPGA 개발 경험 기반 비전 · 이미징 IP 코어 라이브러리
- **CPU 오프로딩** — FPGA가 고부하 연산 처리, 시스템 자원 절약
- **다양한 IP 코어** — 시스템(Multiport · MultiFIFO), 카메라 I/F, 이미지 처리(디베이어 · 히스토그램 · 모폴로지), 디버그
- **압축 IP 코어** — JPEG · Lossless · Quality+
- **FPGA 가상화** — 다수 애플리케이션이 FPGA를 동시 공유
- **GenICam 표준 지원**

**ProcVision Suite**
- C/C++ 기반 커스텀 FPGA IP 코어 개발 · 컴파일
- 비 FPGA 전문가도 알고리즘 구현 가능 → 개발 기간 단축
- OEM/ODM 고객 맞춤형 솔루션 신속 지원

**SkyBoost SDK**
- 고속 RAW → JPEG API
- 소프트웨어 대비 빠른 하드웨어 가속

## VCANUS와 함께하는 Gidel 솔루션 통합

VCANUS는 Gidel 제품의 단순 공급에 그치지 않고, **자체 데이터 플랫폼 (TSLoom)** 및 **AI 비전 플랫폼 (DeepVi)** 과 결합하여 **End-to-End 산업 비전 솔루션**으로 제공합니다.

**고속 · 대용량 이미지 분산 처리 시나리오**

`고속 카메라 → Gidel FantoVision (고속 수신·버퍼링) → VCANUS Flowbroker (지능형 작업 분배) → 분산 처리 노드 1~N → 통합 분석 결과`

- 데이터 손실 없는 고속 수신
- 자동 부하 분산 처리
- 처리 노드 추가만으로 선형 확장

**스테이지 연동 정밀 촬영 및 이미지 병합 시나리오**

`엔코더 → FPGA HawkEye (위치 분석·트리거 생성) → 카메라 + 조명 (동시 트리거) → DMA 버퍼 (Zero Copy) → 병합 영상`

- 위치 기반 정밀 트리거
- 조명 · 카메라 동기화
- 실시간 이미지 병합

**초저지연 웹 기반 모니터링 + AI 실시간 분석**

`카메라 → 현장 AI 처리 (FantoVision) → 지능형 분석 → 초저지연 전송 → 웹 대시보드`
